# Future Regions Pipeline

## Priority 1 — Well-documented, CRCNS available
- Visual cortex (V1) — Allen Institute Neuropixels dataset
- Auditory cortex (A1) — CRCNS ac-1
- Somatosensory cortex (S1) — CRCNS ssc datasets
- Striatum — CRCNS str datasets

## Priority 2 — Moderate documentation
- Cerebellum — CRCNS cb datasets
- Thalamus (VPM/POm nuclei) — check CRCNS
- Amygdala — CRCNS bnst datasets
- Basal ganglia (substantia nigra) — check OpenNeuro

## Priority 3 — Advanced, specialized
- Spinal cord — check CRCNS
- Olfactory bulb — CRCNS ob datasets
- Retina — check OpenNeuro MEA datasets
- Human medial temporal lobe — Quiroga lab datasets

## Notes
- Each region needs: noise floor, spike amplitude, firing rate, 
  waveform duration, cell type composition
- Source every parameter to a peer-reviewed paper
- Validate synthetic output against real data before adding region
